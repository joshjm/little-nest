# Google Drive sync was removed in 1.6

Use [local Wi-Fi pairing or OneDrive](Sync-Setup.md) instead. This page is kept
so links in historical release notes still resolve.

Before updating an old installation, sync both phones using that old version and
export complete JSON backups. Install the update without uninstalling. Local
records are preserved; Google sync is disconnected on this phone. Existing
Google files, OAuth grants and folder access are not deleted or revoked.
Manage those separately in Google Drive and your Google Account.

Pair locally or let one caregiver create a new OneDrive nest and invite the other.
Do not create separate nests on both phones. Historical operations retained on
each phone will merge through the new transport. If records exist only in the
old Google folder, retrieve them using the old app and export a backup before
updating; the new app does not read Google Drive.
