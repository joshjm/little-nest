# Little Nest 1.7.0

## Research-based baby growth charts

- Trends now compares weight, length/height and head circumference with official
  sex-specific WHO Child Growth Standards from birth to five years.
- See the 3rd, 15th, 50th, 85th and 97th percentile curves, all dated measurements,
  and a dashed guide continuing the first entry's percentile for comparison.
- Dated text values include approximate percentiles; charts respect metric and
  imperial preferences and real time gaps between measurements.
- Actual age is the default. A saved adjusted due date enables an explicit
  adjusted-age view. Missing profile information never causes sex/age guessing.
- Official reference data is bundled for offline use, with reproducible source
  extraction and provenance. Existing import identities, storage and sync
  formats are unchanged.

These are reference curves, not forecasts, targets or medical advice. Babies
can change percentiles. WHO weekly/monthly tables are interpolated, so
percentiles are approximate. Length assumes lying down before age two and
standing height afterward; recorded measurements are not position-corrected.
Unsupported ages retain their measurements without a percentile. These are not
preterm charts; ask a clinician about corrected age and local chart guidance.
See [the growth guide](https://github.com/joshjm/little-nest/blob/v1.7.0/wiki/Growth-Charts.md).

## Also included since the previous stable release

The already-merged 1.6 sync changes replace Google Drive with account-free,
encrypted foreground local Wi-Fi pairing and optional OneDrive support.
Existing local records are retained. Old Google connections are removed;
Google files and permissions are not deleted. Back up and sync old installations
before updating both phones. Local pairing needs both apps open on the same
reachable network. OneDrive sign-in is disabled in builds without a publisher
Microsoft application registration; real-account OneDrive and two-physical-phone
acceptance remain separate checks.

Install this same-key APK over the existing app without uninstalling.
Obtainium users can update from the same GitHub repository.
