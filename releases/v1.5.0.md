# Little Nest 1.5.0

Two ways to plan the next feed or nap, plus Little Nest's independent visual
identity. Requires **Android 9 or newer**.

## Install or update

Download **LittleNest.apk** below, not the source-code archives.
Install over the existing app **without uninstalling** to preserve local data.
Export a backup first. This version uses code **6** and the original signing key.

Obtainium users can keep the source `https://github.com/joshjm/little-nest`
and check for updates. This is a stable release with one universal APK.

## New planning comparisons

**Today → Coming up** shows two predictions for daytime milk feeds and naps:

- **Normal schedule:** moving-average clock time for the next daily nap/feed
  number, using up to seven recent matching days within the last 14 days.
- **History-adjusted:** learns the next interval following similar early/late
  and short/long care in this baby's logs. It accounts for the last wake time
  or feeding-session start and shows how much earlier/later the result is.
- Tap for the basis, sample counts, planning windows and missing-data explanations.
  At least four comparable historical days are required; unsupported adjustments
  are shown as unavailable rather than guessed.
- Bottle volume is normalized across units. Breastfeeding minutes are never
  converted to intake. These are observed patterns, not measured sleep debt,
  nutritional requirements or catch-up feeding amounts.
- Existing interval-based alerts, manual intervals, quiet hours, snooze and
  dismiss behavior remain unchanged.

Read the [planning guide](https://github.com/joshjm/little-nest/blob/v1.5.0/wiki/Care-Plan.md)
for grouping, daily-numbering assumptions, daytime limits and safety guards.

## Independent visual identity

Includes the previously source-only 1.4 redesign: warm paper surfaces,
forest-green navigation, bold sans-serif headings, an original woven-nest mark,
rounded activity tiles and labelled Add controls. Forms, charts and history
share the updated palette. Visible import actions use **Import activity CSV**;
existing imports, source identities and data remain compatible.

## Important limitations

Follow baby's cues and your clinician's care plan; never delay feeding for a
prediction. Missing logs, changing routines and illness can make estimates
unreliable. Android may delay notifications; do not rely on them for
time-critical care.

Offline tracking works immediately. Optional two-caregiver Google Drive sync
still requires your own Google Cloud/OAuth configuration; live authorization
between two real accounts has not been verified. All connected-family profiles,
including parent logs and photos, are shared with the partner.

No personal export, database, signing key or OAuth credential is included.
Verify the download with the attached **SHA256SUMS**:

```sh
sha256sum -c SHA256SUMS
```
