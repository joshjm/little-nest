# Little Nest 1.15.0

- One-tap **Wet nappy**, **Poo nappy** and **Start sleep / End sleep** buttons
  at the top of Today. They save straight away with the current time.
- New home-screen widgets: a quick-log row with the same buttons, and an
  at-a-glance card with the last nappy, last sleep and estimated next sleep and
  feed.
- Nappies and other one-moment logs now have a single **Time** instead of Start
  and End.
- The time wheel opens at the current time and no longer asks for a date. A
  time later than now counts as yesterday. Appointments and reminders still ask
  for a date.
- Existing records, imports, backups and sync stay compatible.

Install over your existing app to retain records. Android 9 or newer.
