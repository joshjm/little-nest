# Little Nest 1.3.0

First public release of an original, offline-first Android baby and parent
tracker. Requires **Android 9 or newer**.

## Install

Download **LittleNest.apk** below, open it on your phone and temporarily allow
installation from the browser/file manager if Android asks. The source-code
archives are not installable apps.

If you already have a Little Nest release, install this over it without
uninstalling. This APK retains the original signing certificate and uses
version code 4. Export a backup before updating.

## Obtainium updates

In Obtainium, choose **Add app** and enter:

https://github.com/joshjm/little-nest

Keep prereleases disabled. There is one universal APK per stable release, so no
architecture/flavour selection is needed. Existing matching installations can be
tracked without uninstalling.

## Included

- Breastfeeding/bottle/pumping/solids, diapers, sleep and side-aware timers.
- Growth, health records, milestones, photos and pregnancy/postpartum tracking.
- Local history, charts, reminders, JSON backup and CSV export.
- Local Nara Baby CSV import, duplicate prevention and ongoing-sleep recovery.
- Learned milk-feed and nap windows, optional manual intervals, advance alerts,
  quiet hours, snooze/dismiss and upcoming reminders/appointments.
- Optional Google Drive sharing between exactly two caregiver accounts per
  family folder; offline records merge after syncing.

## Important limitations

- Offline tracking works immediately. **Google Drive requires your own Google
  Cloud/OAuth setup**; it is not preconfigured by installing this APK. Live
  two-account Google authorization has not been verified. Read the
  [Drive setup guide](https://github.com/joshjm/little-nest/blob/main/wiki/Google-Drive-Setup.md).
- All profiles, photos and parent logs in a connected family are shared with
  that partner. Do not share one family folder across unrelated families.
- Feed/nap estimates are planning aids, not medical advice. Follow baby's cues;
  never delay feeding to match an estimate. Alerts are off by default per phone.
- Android can delay notifications and background sync. Do not rely on these for
  time-critical care.
- Not affiliated with Nara. No Nara account, code, artwork or private service is
  bundled. No personal health exports or signing keys are included.
