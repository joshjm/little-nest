# Little Nest 1.9.0

## Easier partner setup: one invite, one scan

- **Family** now starts with a single **Your partner** section. One phone taps
  **Invite partner**, the other taps **Join partner** and scans the code.
- The same code sets up Wi-Fi pairing and, if you already made a OneDrive
  nest, OneDrive sharing too. No more separate nest code to copy and paste.
  After scanning, the joining phone shows **Finish joining OneDrive nest**
  once the Microsoft invitation email has been accepted.
- **Invite by email** (when you have a OneDrive nest): sends the Microsoft
  invitation and opens your email app with a private join code, so you can
  invite your partner when you are not together. They paste it under
  **Join partner -> Or paste a code they sent you**.
- **Join partner's nest** on the welcome screen now opens the scanner straight away.
- Inviting or joining asks for your caregiver name first if it is not set, so
  logs show who recorded them.
- If Wi-Fi pairing is not possible (for example, no Wi-Fi), an invite falls
  back to OneDrive only instead of failing.

## Fixed

- The old "Copy code" option for Wi-Fi pairing produced codes that stopped
  working as soon as you left the app to send them. It has been replaced by
  the email/paste flow above, which only sends the OneDrive part.

No data, storage, import or sync formats changed. Older OneDrive nest codes can
still be pasted. Install this same-key APK over the existing app without
uninstalling; Obtainium users can update as usual.
