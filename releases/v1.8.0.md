# Little Nest 1.8.0

## A calmer, clearer look: "Woven day"

- Each kind of care now has its own thread colour (feeds, sleep, nappies,
  health, parent care), used the same way on every screen.
- **Today** opens with a 24-hour strip. What already happened is drawn solid;
  suggested feed and nap times are dashed outlines, because they are estimates.
  The key below it only lists colours that are actually shown.
- **History** is a day-by-day timeline with date arrows, a date picker and search.
- **Trends** shows this week against last week, a 7-day sleep pattern, charts in
  thread colours and a daily comparison table. WHO growth charts from 1.7 sit in
  the same layout.
- **Family** and settings are tidy grouped lists.
- The app follows the phone's dark mode with a dim, low-glare night palette.
- Times and counts use evenly spaced digits, and chart text follows the phone's
  font-size setting.
- After saving an entry or using a timer, Today scrolls back to the top so you
  can see the result.

No data, storage, import or sync formats changed. Install this same-key APK over
the existing app without uninstalling; Obtainium users can update as usual.
